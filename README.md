# Ubuntu Youth Foundation Website

## Project Overview

The Ubuntu Youth Foundation website is a website project developed for the WEDE5020 module. The website was created for a fictional South African non-profit organisation that focuses on empowering young people through education, digital skills, mentorship and community support.

## Organisation

Ubuntu Youth Foundation is a fictional non-profit organisation established in 2018. The organisation focuses on supporting young people between the ages of 13 and 24, particularly those from disadvantaged communities.

## Website Purpose

The purpose of the website is to:

- Provide information about Ubuntu Youth Foundation.
- Explain the organisation's programmes and services.
- Provide information about volunteering and sponsorship opportunities.
- Allow users to make enquiries.
- Provide contact information for the organisation.

## Target Audience

The primary target audience is young people between the ages of 13 and 24. Secondary audiences include parents, educators, volunteers, sponsors, businesses and community organisations.

## Website Pages

### Home
Provides an introduction to Ubuntu Youth Foundation and highlights the organisation's main programmes.

### About Us
Provides information about the organisation, including its story, mission, vision, target audience and values.

### Programmes
Provides information about the Digital Skills, Academic Support, Career & Mentorship, and School Supplies & Community Support programmes.

### Enquiry
Provides information about volunteering, sponsorship and partnerships, as well as an enquiry form.

### Contact
Provides contact information, organisation locations and a contact form.
